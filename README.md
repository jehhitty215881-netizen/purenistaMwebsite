# 這版：修掉「明暗缺少漸進的層次」的誤判

## 錯在哪

上一版我把形式原理接進評語，其中「漸變偏低 → 明暗缺少漸進的層次，看起來偏平」是錯的。

實測一張軟調雙人作品：

| 指標 | 值 |
|---|---|
| 明度跨度 | **175**（很寬） |
| 對比 | **76**（高） |
| 漸變 | **13** ← 觸發了「看起來偏平」 |

明度從 64 到 239——**這張一點都不平**，卻被說平。

原因是「漸變」量的根本不是那件事。它算的是**畫面亮度能不能擬合出一個平滑的線性或放射狀漸層**
（`r²` × 振幅）。深色頭髮配白紗這種局部結構複雜的畫面，擬合不出全域漸層，分數自然低——
但那跟「平」正好相反。

**而我犯的錯，正好是這整個模組存在的理由：**
我挑「漸變」是因為它在十張測試圖裡的分布幅度最大（8~70），
**沒有去確認它量的是什麼意思**。用鑑別力挑指標、卻沒驗證語意。

## 改了什麼

移除兩個觸發點：**漸變偏低**、**反覆偏低**。

理由不只是漸變量錯東西，更根本的是——**形式原理是十種手法，不是十項要求。**
沒用到漸變或反覆，跟沒用到對稱一樣，都不是錯誤。

留下的四項是**性質上真的算缺陷**的：
主體與背景分不開（對比低）、元素雜亂（單純低）、位置沒有關係（比例低）、
既不統一也不多樣（統多低）。

「畫面平不平」則由**明度跨度**那條誠實地負責（跨度 < 78 才報）。

## 結果

那張作品現在是「**無缺點**」＋「色調和諧、跨度完整、多重構圖」。
而且移掉兩個觸發點後，**十一張測試圖仍然產生 11 種不同的評語組合**，變化度沒有損失。
