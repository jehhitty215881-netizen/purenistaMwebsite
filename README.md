# 這版：構圖判讀的完整審查

把累積的 26 張作品全部跑一遍，逐張對照目測。找到兩個 bug。

## Bug 1：「打破圖案」出現，但「重複圖案」沒有

鏡子那張報「打破圖案 100%」，卻沒有「重複圖案」。
**沒有重複的圖案，就沒有東西可以打破。**

原因：`patternBreak` 確實寫在 `pattern` 的同一個判斷式裡，所以只有偵測到重複才會算。
但**雜訊門檻（0.35）是事後對每一項分別套用的**——
重複圖案 0.204 被當雜訊濾掉，它的「打破」1.000 卻留了下來。

加了守衛：**沒有 pattern 就不留 patternBreak**。
（同樣形式的規則本來就有：偵測到放射線就移除十字、偵測到群像三角就移除中心。）

## Bug 2：最明顯的對角構圖偵測不到

黑白哥德那張人物斜躺，**偵測到八條斜向長線，五條 span 超過 0.7**
（135°/0.88、123°/0.81、117°/0.77⋯），135° 的方向能量也是四個方向裡最高的。
但對角線完全沒觸發。

原因是判準要求「一個對角方向的能量要壓過另一個 **2.2 倍**」。
但真正的對角構圖通常兩個對角都有線——人物本身的軸線加上透視線——比值只有 1.14，永遠過不了。

加了第二條路：**同向的長線群聚**。至少 4 條 span ≥ 0.55 的斜線走同一個對角，
且反向最多 1 條。隨機紋理做不出這種東西。

門檻是量出來的：

| 作品 | 同向 / 反向 | 判定 |
|---|---|---|
| 黑白哥德（斜躺） | **5 / 0** | ✓ 對角線 82% |
| 夜船（樹枝斜掃） | **4 / 0** | ✓ 對角線 74% |
| 鏡子（兩對角都有線） | 5 / 2 | ✗ 不觸發 |
| 彼岸花（放射構圖） | 3 / 1 | ✗ 不觸發 |

一開始我用「比值 ≥ 2.5」，結果鏡子剛好 5/2 = 2.5 擦邊觸發；
改成「≥3 條且反向 ≤1」時彼岸花的 3/1 又擦邊。最後定在 4 條，兩個誤判都消失。

## 過程中順手抓到自己的 bug

第一版改完，合成測試裡的「放射線」從 1.00 掉到 0.66——我改對角線不該影響放射線。
Bisect 後發現是**變數名衝突**：我用的 `ob`、`nA`、`nB` 撞到函式裡既有的變數。
全部改成 `_dg` 前綴後，20 項合成測試逐字元回到 baseline。

## 還沒解決

**狐狸左右分**（左白右黑）的重心是 (0.74, 0.56)，偏右太多——
左邊的白衣角色在白背景上對比太低，沒有進入主體遮罩。這是遮罩問題不是構圖問題。

**極高調白**的重心 (0.31, 0.15) 也偏高，同樣是遮罩只抓到最深的幾處。
