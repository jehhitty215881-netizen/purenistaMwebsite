## 這版新增（回應四則使用者回饋）

### 1. 「本站能偵測的 18 種構圖」總覽（構圖分頁）

回饋 4 點名想要黃金比例、放射線、C型、邊緣構圖——**四種本來就都有**。
問題是報告只列「有偵測到的前幾種」，沒觸發的完全不顯示，所以使用者無從得知。

現在全部列出，分線條／形狀／位置／節奏四類：驗出來的亮起來並顯示分數，
沒偵測到的維持灰色但看得見，點任一項跳到美學專欄看說明。

### 2. QA 新增四則作品健檢問答

- Q：作品健檢能偵測哪些構圖？（列出 18 種＋去哪看）
- Q：為什麼有些構圖沒被偵測到？（沒驗出來不代表構圖不好）
- Q：②「這張是怎麼做出來的」要選哪個？（**只有選「拍的照片」才會用攝影判準**）
- Q：報告太長，只想知道結論？（指向「一句話結論」卡片）

QA 有關鍵字篩選，這四則都搜得到。

### 3. ② 那一題改掉了

原本「用誰的眼光來看」→ 攝影師／平面設計師／插畫師，要求使用者先自我認定專業身分。
現在問「**這張是怎麼做出來的？**」——拍的照片／**遊戲截圖・合成排版**（預設）／自己畫的插畫。

**順帶修掉一個嚴重的預設值錯誤**：原本預設「攝影師」，而曝光、對焦、腳下留白
這些攝影判準是綁在這個選擇上的——等於每個沒動過②的使用者都被套用了攝影標準。

### 4. 英文版連結移進固定分頁列

原本在標題區，分頁列是 sticky 的，一捲就看不到了。現在接在「備註」後面，紫色外框。
若點了 404 代表 `en.html` 沒上傳，兩個檔案要放同一層。
