# 新增：命名與標籤

你清單裡的 **#2 標題產生器** 和 **#4 標籤推薦**。

選這兩個的理由：你現有工具是「靈感 → 製作 → 健檢」，
但作品做完之後**要叫什麼名字、發文打什麼標籤**還是卡住——
那是最後二十分鐘，而且剛好接在上一版「創作動線」的最後一段（發布前）。

## 標題產生器

輸入關鍵字（可留空），選風格，一次給 6 個：

| 風格 | 產出範例 |
|---|---|
| 詩意中文 | 沉入月色、關於薔薇色的一切、月色未眠 |
| 日系 | 月のうた、さよなら夜、ひとひらの花 |
| 英文 | Where the Moon Sleeps、Letters to the Rose |
| 可愛 | 月的小秘密、貓的下午茶、星星泡泡 |
| 暗黑 | 薔薇與腐朽、凋零的花、最後的夜 |

**是模板生成不是隨機拼貼**——20 個意象 × 8 種情緒 × 5 種風格的句型，
所以同一個關鍵字每次骰都不一樣，但讀起來像人寫的。

關鍵字中英日都認得：打「月光」「moon」「ムーン」都會找到同一組詞。

## 標籤推薦

依關鍵字＋本月節氣自動產生，點一下複製。
會提醒「挑 5～8 個就夠，太多反而稀釋」。

## 節氣靈感

顯示本月適合的題材（例如 8 月＝星、夜、光 ＋ #煙火 #盛夏 #夜空），
點題材就直接拿去生標題。

**這是按月份的固定循環，所以永遠正確、不用任何人維護。**

## 為什麼沒做「即時熱門標籤」

那需要伺服器持續蒐集所有人的貼文。GitHub Pages 是純靜態，沒有伺服器。
而且**沒人維護的「熱門」比沒有更糟**——會一直顯示過期資訊卻看起來像即時的。

同理沒做的還有：收藏靈感牆、色票收藏（跨裝置同步需要帳號系統）、流行趨勢。

## 為什麼沒做清單裡的其他項目

| 項目 | 原因 |
|---|---|
| 創作者百科、名詞百科、構圖模板 | **你已經有了**——美學專欄裡有 26 條構圖、10 項形式原理、13 項光影 |
| 靈感輪盤、創作 Prompt、隨機限制 | **你已經有了**——配色靈感的四顆骰子 |

| 節日企劃 | 已折進「節氣靈感」，改成按月自動算，不用維護 |
