# 這版：回應四則使用者回饋

## 回饋 4「希望有更多構圖，例如黃金比例、放射線、C型、邊緣構圖」

**這四種全部都已經有了。**

| 他想要的 | 程式裡本來就有 |
|---|---|
| 黃金比例構圖 | 黃金比例點 |
| 放射線構圖 | 放射線／消失點 |
| C型構圖 | C 形曲線 |
| 邊緣構圖 | 邊緣張力 |

他不是在要新功能，是**不知道這些存在**——報告只顯示「有觸發的前 5 種」，
沒觸發的就完全看不到，所以使用者無從得知這 18 種的存在。

**新增「本站能偵測的 18 種構圖」總覽**，放在構圖分頁。
分成線條／形狀／位置／節奏四類，這張作品驗出來的會亮起來並顯示分數，
沒偵測到的維持灰色但**仍然看得見**。每一項都能點進美學專欄看說明。

這同時回應了回饋 3——**能力藏起來，詞彙也沒機會學**。現在使用者至少知道
「原來還有 C 形曲線這種東西」，而且知道去哪裡查。

## 回饋 3「看不懂、第二版出現攝影師／平面設計師／插畫師」

**② 那一題整個改掉。** 原本要求使用者先自我認定專業身分。做遊戲截圖的人
不會覺得自己是「平面設計師」，自然不知道該選哪個。

現在問「**這張是怎麼做出來的？**」——拍的照片／**遊戲截圖・合成排版**（預設）／自己畫的插畫。
問的是作品不是人。

**順帶抓到一個更嚴重的預設值錯誤**：原本預設是「攝影師」，而 v4.5 之後曝光、對焦、
腳下留白這些攝影判準**是綁在這個選擇上的**。等於每個沒動過②的使用者
都被套用了攝影標準——在一個做遊戲截圖的網站上，這是預設給所有人不適用的批評。

## 回饋 2「希望先給簡短結論」＋「英文版無法使用」

**簡短結論**：報告最上方已有「一句話結論」卡片——整體評價、
最該改的一件事、最該保留的一件事。

**英文版**：連結原本在標題區，但分頁列是 sticky 固定的，標題一捲就不見了。
已移進分頁列（接在「備註」後，紫色外框），任何位置都點得到。
若點了 404 代表 `en.html` 沒上傳，兩個檔案要放同一層。

## 回饋 1「修正方向的數字會超出邊框」

`.cm-fix` 完全沒有 CSS 規則，吃了瀏覽器預設——而預設把 `<ol>` 的數字畫在
內容框**外面**。已補上 `padding-left` 並把數字改成主題色。
