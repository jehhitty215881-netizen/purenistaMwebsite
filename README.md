| 修正 | 原本的問題 |
|---|---|
| 傾斜不再套用在插畫 | 畫布沒有水平可言，卻是權重 100 的最高優先缺點 |

| 評級與缺點一致性守衛 | 「有明顯問題」和「沒有明顯要改的地方」同時出現 |
