## 這版修的（重要）

### 報告分頁「沒有數據」

上一份給你的檔案漏掉了一個修正檔，導致**四個分頁全是空的**。兩個原因：

**① 區塊標題帶編號。** `buildReport` 產生的是 `<h3>1. 主體辨識`，
但分組程式比對的是 `<h3>主體辨識`——前綴永遠對不上，每個區塊都落到最後一個分頁。
改成用正規式剝掉編號再比對。

**② `<div class="chk-grid">` 開了沒關。** 原本靠瀏覽器在容器結尾自動收尾，
但拆成分頁之後，那個 wrapper 只存在於第一個分頁，其餘分頁的內容全部被吃進去。
改成把 wrapper 從前言拿掉，每個分頁自己開一組、自己關。

**這次有真的測。** 15 項測試，用的是 `buildReport` 實際產生的結構
（含編號前綴、未關閉的 grid、13 個區塊）：分組正確、區塊一個不少、
每個分頁的 div 開合各自平衡、前言留在分頁上方。上一版就是**沒測結構平衡**才爆掉的。

### 移除 AI 視覺輔助選項

那個功能需要自備付費 API key，沒辦法自動化，介面又佔一大塊。已整個移除。

**代價要說清楚**：那是唯一能處理**側臉和被手遮住的臉**的方法，
LBP cascade 做不到。所以插畫的人數與景別判讀會回到只靠正面臉偵測的水準。
以後想加回來隨時說。
