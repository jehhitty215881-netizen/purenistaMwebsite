## 測試抓到的兩個 bug

**① 「月光」會被判成「晨光」。**
比對是逐一掃過意象表，先命中誰就用誰。意象從 20 擴到 80 之後，
「光」這個單字會搶先攔截「月光」——因為它剛好排在前面。
改成**最長匹配優先**：現在「月光」給月、「極光」給極光、「彼岸花」給曼珠沙華。

這個 bug 只在擴充後才會出現，而且是間歇性的（連跑五次才失敗兩次）——
沒有那組測試根本抓不到。

**② 一個英文模板缺主意象**（`The Distance to {m2}` 語意不完整），已修。
