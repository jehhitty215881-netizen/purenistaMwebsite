# 作品健檢 v3.8

## 修掉「有時候偵測不到人」

找到原因了，是個真的 bug：

原本的流程是「**先用原尺寸偵測，只有在完全找不到任何臉的時候**，才放大 2 倍重試一次」。

問題就在「完全找不到」這個條件。一張圖裡有大小兩個角色時，大的臉抓到了 →
「有找到東西」→ 重試永遠不會觸發 → **小的那個角色就永久遺失**。
這正好是「有時候偵測不到」的樣子：不是隨機，是固定漏掉比較小的那個。

改成 **一律先放大 1.5 倍再偵測一次**，不再有條件重試。

| 臉的尺寸 | 舊（1x） | 新（1.5x） |
|---|---|---|
| 16px | ✗ | ✓ |
| 18px | ✗ | ✓ |
| 20px | ✗ | ✓ |
| 24px | ✓ n=6（剛好擦過門檻） | ✓ **n=50** |
| 40px | ✓ n=46 | ✓ n=90 |

偵測下限從 24px 降到 16px（cascade 的視窗固定是 24×24，要看到更小的臉只能把圖放大）。
而且原本抓得到的每個尺寸，信心值都大幅提高——24px 那格從 n=6 變 n=50，
本來只差一點就被 minNeighbors 濾掉。

minNeighbors 也從 5 放寬到 4，給真實模型多一點餘裕（我的合成圖案是完美的，真實臉會模糊些）。

耗時 245ms → 626ms，但在 Worker 裡跑，頁面不受影響。

## v3.7：修掉三個「不管什麼圖都會出現」的誤判

- **「暗部壓成死黑」**：暗部統計寫在 `if(mask)` 外面，整張圖都算。黑底插畫的背景本來就是純黑，
  所以永遠 100% 中。改成只算主體範圍內。EVANESCENT 89%→7%、彼岸花 76%→0%、圓形星空 98%→3%。
- **「局部欠曝」**：`evStd` 量的是明暗不均勻程度，不是曝光。原本等於「只要有對比就是欠曝」，
  9 張測試圖全中。改成要有實際證據，剩 2 張（主體平均亮度確實只有 46 和 50）。
- **「主體略帶柔焦」**：報告的分支是 `if(清晰) … else if(失焦) … else 柔焦`，else 是預設值。
  平塗插畫永遠進不了「清晰」。插畫模式下現在完全不報對焦。

## v3.6：用 9 張真圖校準

- **重複圖案** 原本 9 張誤判 8 張（77–100%），全部滿分等於沒有判讀。重新校準後剩 4 張且分數散開。
- **體積光** 完全相反：水平的水面反光帶被判成光柱 0.85，真正的斜向光束卻是 0.00。
  加了「光從上方來，光柱必為垂直或斜向」的方向閘門，並允許單一寬光柱觸發。
