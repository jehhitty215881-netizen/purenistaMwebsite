# 作品健檢 v4.4

## 純白／純黑設計不再被判成過曝／死黑

v4.2 修了「曝光均勻度」，但**漏了「亮部細節」那一欄**——那是另一個獨立的判定。
拿一張純白設計實測（白花、白蕾絲、白髮、黑底）：

| | 數值 |
|---|---|
| p10 / p50 / p90 | 166 / 230 / **250** |
| 亮部（>245） | **22.0%** |
| clipRatio | **7.23%**（門檻 5%） |

→ 判成「主體局部過曝」。一張整體設計就是白的作品。

### 改法不只是關掉，而是換成有用的話

純白是顏料，不是曝光失誤，這兩者從像素分不出來。但**那個數字本身有價值**，
只是意義不同——它說的是**主體有多少比例已經完全平掉、沒有明暗資訊了**。

純白設計本來就是在管理這個數字：留白要夠才透亮，但如果關鍵的轉折處也一起平掉，
立體感就消失了。所以改成：

| 作品 | 舊 | 新 |
|---|---|---|
| 純白設計 | 主體局部過曝 | **高調（純白 7%）** |
| ROSY DESIRE | 暗部死黑 | **低調（純黑 26%）** |
| 彼岸花／雙人淺藍／PostOffice | 良好 | 良好（不變） |

說明文字也一併換掉，改成講怎麼自己確認：
**轉灰階瞇眼看，剩下的形狀就是觀眾實際讀到的。**

插畫模式下這兩項也不再進入「缺點」清單與「技術完成度」，
因為它們不是缺點；照片模式維持原本的判定。

## 到目前修掉的七個「必現誤報」

成因全部一樣：**用一個沒有鑑別力的量，去做一個需要語意的判斷。**

| 誤報 | 錯在哪 |
|---|---|
| 暗部壓成死黑 | 暗部統計寫在遮罩外，黑底插畫的背景本來就是純黑 |
| 局部欠曝 | `evStd` 量的是明暗不均勻度，不是曝光 |
| 主體略帶柔焦 | 報告的 `else` 分支就是柔焦，平塗插畫永遠進不了「清晰」 |
| 視覺焦點分散 | 3×3 分區最大值的均勻基準就是 0.111，門檻卻設在 0.15 |
| 文字版面 | 「邊緣密集＋低飽和」＝蕾絲、髮絲、星點全中 |
| 人物下緣貼齊 | 用遮罩高度當「全身照」的證據 |
| **主體局部過曝** | **純白顏料和過曝在像素上是同一件事** |

判斷方法：**一個判讀如果不管什麼圖都給同樣答案，它就沒有在判讀。**
