## 主題與配色的綁定有檢查

主題是用 id 指向配色的，如果新主題指到不存在的配色，
**畫面不會壞掉，只會靜靜地顯示不出色票**。

所以 patch 裡加了驗證：58 個主題全部指向存在的配色，缺一個就拒絕建置。

# 上一版：標題產生器的兩個修正

**「沙灘」跳出砂糖**——不是誤讀，而是根本沒辨識到，然後默默改用亂數。
20 個常見詞測下來 18 個辨識不到。改成**辨識不到就直接用你打的字**，
所以打什麼都能用，詞庫大小不再是問題。

**各風格內容重複**——六個標題原本共用同一個意象，而且沒記錄用過的句型。
現在每行意象都不同，並記住最近 30 個模板跳過。實測連骰 8 次共 48 個標題，
**47 種不同句型**。
